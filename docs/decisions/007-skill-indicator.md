# 007. 공격 예고 인디케이터

- **상태:** 확정
- **결정일:** 2026-08-08

`CLAUDE.md` §5 의 VFX 3요소 중 **예고(지면 인디케이터)** 를 어떻게 그릴지 정한다.
판정 자체는 결정 006 §6 과 `SkillShape` 가 이미 담당한다.

---

## 1. 바닥에 깔고 알파를 높게 쓴다

캐릭터 위에 덮지 않는다. 지면에 깔되, 몬스터가 겹쳐 서면 가려지므로 **알파를 높게** 준다.
정렬은 바닥 타일맵 위 · 캐릭터 아래.

## 2. 메시로 그리지 않는다 — 도트가 깨진다

처음에는 판정 도형 그대로 메시를 생성하는 안을 검토했다.
판정과 어긋날 수 없다는 장점이 컸지만 **폴리곤의 매끈한 가장자리가 64px 도트 위에서 튄다.**
이 게임은 픽셀 아트이고 인디케이터는 화면에서 가장 자주 보이는 이펙트다.

## 3. 런타임 래스터화 + Point 필터

도형을 폴리곤이 아니라 **픽셀 격자에 찍어서 텍스처로 만든다.**

```
SkillShapeParams
   → 텍셀마다 "이 점이 범위 안인가" 검사   ← 판정과 같은 수학
   → 64 px/unit 텍스처에 기록
   → SpriteRenderer · Filter Mode: Point
```

| 얻는 것 | 어떻게 |
|---|---|
| **도트 유지** | 가장자리가 픽셀 단위로 계단이 진다. 타일과 같은 64 PPU 라 격자가 맞는다 |
| **판정과 일치** | 같은 수학으로 찍으므로 1픽셀 안에서 정확하다 |
| **아트 불필요** | 부채꼴 각도가 스킬마다 달라도 된다 |

**타일맵 색칠(`Tilemap.SetColor`)은 쓰지 않는다.** 가능은 하지만
(단, `Tile` 기본 `flags` 가 `TileFlags.LockColor` 라 `SetTileFlags(TileFlags.None)` 을
먼저 부르지 않으면 조용히 아무 일도 일어나지 않는다) 이 용도엔 네 가지가 걸린다.

1. **판정이 타일 격자가 아니다.** 100° 부채꼴을 온전한 타일로 표현하면
   보이는 범위와 맞는 범위가 달라진다 — §5 가 막으려는 바로 그것이다
2. 게임플레이 타일맵을 변형하고 되돌려야 한다. 예고가 겹치면 복원 순서가 꼬여 색이 남는다
3. `SetColor` 는 청크 메시를 다시 만든다. 매 프레임 갱신에 비싸다
4. 곱셈 틴트라 어두운 바닥 위에서 빨강이 거의 안 보인다

## 4. 8방향으로 구워 캐시한다

**픽셀 아트는 회전시키면 어긋난다.** 그래서 런타임 회전을 쓰지 않고
프로젝트의 8방향 규약(`CLAUDE.md` §4)에 맞춰 `스킬 × 8방향` 텍스처를 만들어 재사용한다.

- 첫 사용 때 한 번만 생성한다. 256×256 기준 6.5만 번 점 검사 — 한 번뿐이다
- 같은 스킬을 쓰는 몬스터가 여럿이어도 텍스처는 하나다
- 매 프레임 비용은 0. 위치만 옮기고 알파만 바꾼다

래스터라이저가 **1~2px 테두리**를 함께 찍는다. 도트 게임 예고선의 관용적인 모양이다.

## 5. 몬스터 공격을 세 단계로 쪼갠다

지금 `MonsterController.PerformAttack` 은 사거리에 들어오면 **즉시** 때린다.
예고를 보여주려면 단계가 필요하다.

```
예고 (인디케이터 표시)  →  판정  →  경직
```

`MonsterDefinition` 에 `telegraphDuration` 을 추가한다. 등급별 기본값은 다음과 같다.

| 등급 | 예고 | 근거 |
|---|---|---|
| Normal | **0.30초** | 반응은 되지만 여유는 없다 |
| Elite | **0.45초** | 피할 수 있다 |
| Boss | **0.70초** | 패턴을 읽고 움직이는 시간 |

**보스일수록 길다.** 범위가 넓고 아프니 피할 여지를 줘야 "패턴 공략" 이 성립한다.
짧게 주면 그냥 맞는 공격이 되어 회피의 의미가 사라진다.

> 임시값이다. 실제로 맞아보고 조정한다.

플레이어는 애니메이션으로 예고를 표현하므로 인디케이터를 끈다.
같은 컴포넌트에 `showIndicator` 플래그만 둔다 — 판정 경로는 하나로 유지한다.
