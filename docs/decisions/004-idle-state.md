# 004. Idle 은 전용 아트로 만든다

- **상태:** 확정
- **결정일:** 2026-08-01

## 배경

Idle(정지) 상태를 추가하면서 "걷기/달리기 시트의 0번 프레임을 재사용하면
텍스처 추가 없이 끝나지 않는가" 라는 안이 먼저 검토되었다.

**재사용할 수 없다.**
`Animation_Knights-Walking` / `Animation_Knights-Running` 의 0번 프레임은
중립 포즈가 아니라 **동작이 이미 시작된 프레임**이다.
그대로 Idle 로 쓰면 서 있는 자세가 걷기 도중 자세로 보인다.

## 결정

**Idle 은 8방향 1프레임 전용 스프라이트 8장으로 새로 제작한다.**

- 파일명은 기존 규약 그대로:
  `01_front_idle_1x1.png` ~ `08_front_faces-screen-left_idle_1x1.png`
- 셀 규격은 걷기·달리기와 **완전히 동일**하게 256 × 256, 캐릭터는 셀 중앙 정렬.
  어긋나면 Idle ↔ Walk 전이에서 캐릭터가 튄다.
- 임포트 설정도 동일: PPU 256, Mesh Type Tight, Filter Point,
  Android/iOS 오버라이드 RGBA ASTC 4×4

## 용량

| | 장당 | 8장 합계 |
|---|---|---|
| 무압축 RGBA32 | 256 KB | 2 MB |
| **ASTC 4×4** | 64 KB | **512 KB** |

나중에 숨쉬기 애니메이션(2~4프레임)으로 확장해도 ASTC 기준 2 MB 수준이므로
지금 구조를 바꾸지 않고 클립 모션만 교체하면 된다.

## 파급 효과

- **트림 작업은 Idle 아트가 들어온 뒤에 수행해야 한다.**
  현재 측정한 불투명 영역 합집합(179 × 211)은 walk + run 16장 기준이다.
  Idle 포즈가 그 범위를 벗어나면 잘려나가므로,
  **24장으로 합집합을 다시 계산**한 뒤 크롭 rect 를 확정한다.
- Animator 블렌드 트리에 Idle 스테이트가 추가된다 (결정 001 구조 유지).

## 미해결

- 방향 파라미터를 latch 방식(`MoveX`/`MoveY` 가 0으로 돌아가지 않고
  `Speed` 가 상태를 가름)으로 갈지 확정 — 결정 001 의 "정지 시 마지막 방향 유지" 항목.
  2D Simple Directional 블렌드 트리는 입력이 `(0,0)` 이면 8개 모션을 평균내
  방향이 뭉개지므로, Idle 을 붙이는 시점에 반드시 결론이 필요하다.
