# 미결정 사항 (Open Decisions)

> 기획서 §14 기준. 결정되면 `상태`를 `확정`으로 바꾸고 `결정 내용`과 `결정일`을 채웁니다.
> 확정된 항목은 `CLAUDE.md` 의 해당 절에도 반영합니다.

> 🚧 표시는 **코드 작성을 실제로 막고 있는 항목**입니다. 구현 착수 전에 먼저 결정해야 합니다.

| # | 항목 | 상태 | 결정 내용 | 결정일 |

| 1 | 플레이어블 캐릭터 및 시작 무기 확정 | 미정 | 현재 아트는 Knights 1종만 존재 | |

## 결정 기록 방법

새 결정이 생기면 이 파일의 표를 갱신하고, 배경 설명이 긴 경우
`docs/decisions/NNN-제목.md` 형태로 별도 파일을 추가합니다.

예: `docs/decisions/003-stat-formula.md`
