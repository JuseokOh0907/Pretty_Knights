# 검격·스킬 이펙트 아트 규격

> **판정 도형을 그대로 보여주면 칼이 아니라 부채가 된다** (2026-08-09 확정).
> 부채꼴 전체를 채우면 원점 근처까지 빽빽해서 휘두르는 것으로 읽히지 않는다.
> 그래서 **맞는 범위와 보이는 그림을 갈랐다** — 판정은 `SkillShape`,
> 그림은 `SkillEffectDefinition`(SO)이 맡는다.
>
> 근거는 [`../decisions/008-impact-vfx.md`](../decisions/008-impact-vfx.md) §8.
> 범위를 그대로 그리는 래스터화는 이제 **빨간 예고 전용**이다.

---

## 0. 무엇을 그리는가

| 이펙트 | 쓰는 곳 | 우선순위 |
|---|---|---|
| **검격** (`Effect_Slash`) | 플레이어 기본 공격 | **먼저** — 지금 임시 표시로 돌고 있다 |
| 전방 베기 | 스킬 1 | 스킬 구현 때 |
| 관통 직선 | 스킬 2 | 〃 |
| 광역 폭발 | 스킬 3 | 〃 |
| 몬스터 물리 공격 | 몬스터 타격 | 나중 — 지금은 **빨간 예고만** 쓴다 |

**몬스터는 아트가 없어도 된다.** 빨간 예고 → 판정 흐름이 이미 성립한다.
예고와 임팩트가 같은 도형을 연달아 그리면 같은 그림을 두 번 보는 셈이라
"예고를 보고 피한다" 는 신호가 오히려 흐려진다.

## 1. 픽셀 규격

**PPU 는 64 다. 타일과 같다.**

캐릭터는 256 이지만 이펙트는 타일을 따라간다. 이유가 둘이다.

1. **크기가 감당된다.** 사거리 1.6유닛짜리 반원을 캐릭터 밀도(256)로 그리면
   한 변이 820px 이 된다. 64 면 205px 이라 손으로 찍을 수 있다
2. **예고와 결이 맞는다.** 지면 예고는 타일 격자에 맞춰 64로 찍힌다
   (결정 007). 예고와 타격이 다른 크기의 도트면 같은 공격으로 안 보인다

> 이펙트 도트가 캐릭터보다 굵게 보이는 것은 **의도된 것**이다.
> 픽셀 게임에서 이펙트를 캐릭터보다 굵게 잡는 것은 흔한 선택이고,
> 굵은 쪽이 빠르게 지나가는 그림에서 형태가 더 잘 읽힌다.

### 캔버스 크기 정하는 법

```
픽셀 = 월드 유닛 × 64
캔버스 = 그 이펙트가 실제로 차지하는 사각형을 8의 배수로 올림
```

| 이펙트 | 차지하는 범위 | 캔버스 | 프레임 |
|---|---|---|---|
| **검격** (반원 · 사거리 1.6) | 3.2 × 1.8 유닛 | **224 × 128** | 5 |
| 전방 베기 (반원 · 2.2) | 4.4 × 2.4 | 288 × 160 | 6 |
| 관통 직선 (길이 5 · 폭 1.2) | 1.6 × 5.2 | 104 × 336 | 6 |
| 광역 폭발 (반지름 2.5) | 5.4 × 5.4 | 352 × 352 | 8 |

**빈 여백을 크게 두지 않는다.** 캔버스가 두 배면 메모리도 네 배다.

- **Pivot: Center** — 코드가 중심을 기준으로 놓는다
- Filter Mode **Point** · Compression **RGBA ASTC 4×4** (`CLAUDE.md` §4)

## 2. 방향은 5장만 그린다

8방향이지만 **좌우가 거울인 것은 한쪽만 그린다.** 코드가 반전해서 쓴다.

```
그린다                      반전으로 대신한다
01_front            (아래)
02_front_faces-screen-right  →  08_front_faces-screen-left
03_faces-screen-right        →  07_faces-screen-left
04_back_faces-screen-right   →  06_back_faces-screen-left
05_back             (위)
```

검격은 **손 소유가 드러나지 않는 추상적인 호**라서 반전해도 깨지지 않는다.
`CLAUDE.md` §4 의 "반전하면 손이 바뀌는 방향은 전용 아트" 규칙은
캐릭터 몸에 대한 것이고 여기엔 해당하지 않는다.

**5장 × 6프레임 = 30장**이면 한 이펙트가 완성된다. 8방향을 다 그리면 48장이다.

### 파일 이름

기존 캐릭터 규칙을 그대로 따른다 (`CLAUDE.md` §4).

```
{순번}_{방향}_{이펙트이름}_{프레임레이아웃}.png

03_faces-screen-right_slash_5x1.png     오른쪽 검격, 가로 5프레임 1행
01_front_slash_5x1.png                  아래 검격
```

넣는 곳: `Assets/Art/Effects/Slash/`

## 3. 그릴 때 지킬 것

- **0번 프레임이 가장 짧고 얇다.** 칼이 들어가는 순간이다
- **가운데 프레임이 가장 길고 밝다.** 여기가 타격 순간이다
- **마지막 프레임은 잔상만.** 얇고 흐리게 사그라진다
- **색은 2~3단계로 끊는다.** 매끄러운 그라데이션은 도트가 아니라 그림자다
  (심 · 중간 · 외곽 정도)
- **호의 안쪽을 채우지 않는다.** 이게 부채와 칼자국을 가르는 지점이다.
  바깥 테두리를 따라 흐르는 **초승달**이어야 한다
- 흰색~연노랑 계열로 그리고 색은 비워 둔다. `Tint` 로 물들인다

```
     ▁▂▃          ▁▂▃▃▃         ▁▂▃▃▃▃▃        ▁▂▃▃▃        ▁▂▁
    ▂▃            ▂▃▃▃▃         ▂▃▃▃▃▃▃        ▂▃▃▃          ▁
   0번            1번            2번 (타격)     3번           4번
   들어간다        벌어진다        가장 길다      빠진다        잔상
```

## 4. 에셋 만들기

`Create > Pretty Knights > Skill Effect Definition` → `Assets/Data/Effects/Effect_Slash.asset`

| 칸 | 값 | 비고 |
|---|---|---|
| Clips | **5개** | Direction 을 01·02·03·04·05 에 맞추고 Frames 에 순서대로 |
| Frames Per Second | **20** | 5프레임이면 0.25초 |
| Forward Offset | **0.6** | 시전자에서 앞으로 미는 거리 |
| Vertical Offset | **0.4** | 발밑이 아니라 몸통 높이에서 터지게 |
| Tint | 흰색 | 아군은 흰색, 적 아트가 생기면 붉게 |
| Scale | 1 | 아트가 커지면 여기서 줄인다 |
| **Follow Caster** | **켬** | 아래 §5 |

그리고 `Player.prefab` 의 `PlayerAttack` 에서

- `Attack Effect` → `Effect_Slash` ★
- `Show Range When No Art` → **끈다** (아트가 들어왔으므로)

## 5. 검격은 몸을 따라간다

`Follow Caster` 를 **켠다.** 휘두르는 0.25초 사이에 걸어가면
칼자국만 뒤에 남아 몸과 떨어져 보이기 때문이다.

**예고는 반대로 절대 따라가면 안 된다.** 표식이 따라오면 피할 방법이 없다.
같은 "따라간다" 라도 둘의 답이 정반대인 이유는 **무엇을 약속하는 그림인가**가 다르기 때문이다.

| 그림 | 약속 | 따라가나 |
|---|---|---|
| 예고 (빨강) | "여기가 위험해진다" — 앞으로의 약속 | **아니오.** 따라오면 거짓말이 된다 |
| 검격 | "방금 휘둘렀다" — 몸짓의 잔상 | **예.** 몸에서 떨어지면 거짓말이 된다 |
| 지면 장판 · 폭발 자국 | "이 자리가 탔다" | 아니오 |

> 따라갈 때도 **부모를 바꾸지 않는다.** 풀은 Boot 에 상주하는데 게임플레이 씬의
> 오브젝트에 붙이면 씬이 내려갈 때 함께 파괴되어 풀이 죽은 참조를 든다.
> 좌표만 매 프레임 따라간다.

---

## 6. 아트가 들어오기 전까지

`Attack Effect` 가 비어 있으면 판정 범위를 그대로 그리는 **임시 표시**가 돈다.
지금 보이는 부채 모양이 그것이다. 아트가 들어오면
`Show Range When No Art` 를 꺼서 완전히 끈다.

**몬스터 쪽은 이미 껐다.** 빨간 예고 하나로 끝난다.
