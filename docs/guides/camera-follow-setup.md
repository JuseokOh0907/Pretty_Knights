# 카메라 추적 설정 가이드

> Goblin 맵이 44,780칸 규모가 되면서 **방 하나 = 화면 하나**가 성립하지 않는다.
> 카메라가 캐릭터를 따라가야 하고, 맵 가장자리에서 빈 공간이 보이지 않게 가둬야 한다.

---

## 왜 카메라를 프리팹의 자식으로 두지 않는가

| | 프리팹 자식 | **씬 + 스크립트** |
|---|---|---|
| 부드러운 추적 | 불가 (즉시 고정) | 가능 |
| 맵 경계 제한 | 불가 | 가능 |
| 층·씬별 설정 | 불가 | 가능 |
| 인스펙터 연결 | 필요 없음 | **필요 없음** (자동 탐색) |

`CameraFollow` 는 대상을 `ServiceRegistry` 에서 찾는다.
`PlayerController` 가 자기를 등록하므로 **연결 작업이 없다.**
몸은 씬마다 새로 생기지만 카메라가 매번 다시 찾는다.

## 1. 붙이기

`Ingame_Horizontal` 의 **`Main Camera`** 를 선택하고 `CameraFollow` 를 추가한다.

| 필드 | 기본값 | 의미 |
|---|---|---|
| Smooth Time | `0.15` | 따라붙는 데 걸리는 시간. 0이면 즉시 |
| Dead Zone | `0.35` | 이 반경 안에서는 카메라가 안 움직인다. 미세한 떨림을 막는다 |
| Snap Distance | `8` | 대상이 이만큼 멀어지면 보간 없이 즉시 붙는다 |
| **Bounds Source** | 비움 | **여기에 층의 Floor 타일맵을 넣는다** |
| Bounds Padding | `0` | 경계를 안쪽으로 좁힌다 |

## 2. 경계 지정

`Bounds Source` 에 **그 층의 Floor 타일맵**을 넣는다. 예를 들어 1층이면 `1Floor`.

타일이 실제로 깔린 범위(`cellBounds`)를 읽어 카메라를 그 안에 가둔다.
`Guide` 가 아니라 `Floor` 를 쓰는 이유는 **플레이어가 실제로 갈 수 있는 영역**이 기준이어야 하기 때문이다.

씬 뷰에서 `Main Camera` 를 선택하면 **하늘색 사각형**으로 경계가 그려진다.

> 층마다 범위가 다르다.
> ```
> 1Floor  x  -90..56   y  -78..83
> 2Floor  x   -3..167  y -143..121
> 3Floor  x  -49..45   y  -12..50
> ```
> 층 전환이 붙으면 `SetBoundsSource(tilemap)` 을 호출해 바꾼다.
> 지금은 시작 층의 Floor 를 넣어두면 된다.

## 3. Snap Distance 가 하는 일

세이브를 복원하면 `GameRoot` 가 플레이어를 저장된 자리로 **순간이동**시킨다.
이때 카메라가 부드럽게 따라가면 맵을 가로질러 한참 흘러간다.

`Snap Distance` 를 넘는 이동은 즉시 붙는다. 층 전환·포탈에도 같은 규칙이 적용되므로
나중에 따로 처리할 필요가 없다.

## 4. 확인

1. Boot 씬에서 재생 → 카메라가 캐릭터를 따라오는지
2. **맵 가장자리로 걸어가 보기** — 화면 밖 빈 공간이 보이면 `Bounds Source` 가 비었거나 잘못된 타일맵이다
3. 제자리에서 미세하게 움직여 보기 — 카메라가 떨리면 `Dead Zone` 을 올린다
4. 세이브 복원 후 재시작 — 카메라가 캐릭터 위에 **이미 가 있어야** 한다. 흘러가면 `Snap Distance` 를 낮춘다

## 5. 아직 없는 것

- **층 전환** — 층이 바뀔 때 `SetBoundsSource` 를 호출할 주체가 없다
- **룩어헤드** — 진행 방향으로 화면을 살짝 밀어주는 처리. 필요해지면 추가
- 세로 모드 카메라 — `Ingame_Vertical` 은 자동 사냥이라 요구가 다를 수 있다
