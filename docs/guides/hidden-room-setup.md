# 히든 방 배치 가이드

> **지금 씬에 `NoSpawnZone` 이 0개다** (2026-08-09 확인).
> 벽(`1FHiddenRewards` · `2FHiddenRewards`)과 `DestructibleTilemap` 6개는 이미 있다.
> 남은 것은 **방 안쪽을 표시하는 일**과 **`WalkableArea` 에 벽을 물리는 일**이다.

---

## 0. 히든 방은 구역이 아니다

이걸 먼저 잡아야 나머지가 읽힌다.

```
히든 방 = 층 안의 한 부분.  별도 areaId 도, 별도 씬 오브젝트도 아니다.
          입구만 부술 수 있는 벽으로 막혀 있고 안쪽은 그냥 그 층의 바닥이다.
```

그래서 **`WalkableArea` 는 방 안쪽을 "설 수 있는 곳" 으로 판정한다.** 맞는 판정이다 —
부수고 들어가면 실제로 설 수 있다. 거기서 빼면 세이브 복원·포탈 도착 보정·
경로 탐색이 전부 히든 방을 "갈 수 없는 곳" 으로 읽는다.

막고 싶은 것은 지형이 아니라 **뿌리는 행위**다. 그래서 층위가 따로 있다.

| 층위 | 하는 일 |
|---|---|
| `1FHiddenRewards` 타일맵 | 입구를 막는 **벽**. 부수면 열린다 |
| `DestructibleTilemap` | 그 벽을 칸 단위로 부술 수 있게 한다 |
| `WalkableArea.Breakable` | **부수기 전까지는 벽**이라고 알려준다 |
| `NoSpawnZone` | 방 **안쪽**에 몬스터·오브젝트를 안 뿌린다 |

**네 개가 다 있어야 성립한다.** 지금 앞의 둘만 있다.

---

## 1. `WalkableArea` 에 벽을 물린다 — 먼저 할 것

**이게 빠지면 `NoSpawnZone` 을 아무리 잘 놓아도 새어 나간다.**
`Breakable` 이 비어 있으면 부수기 전 벽칸이 통행 가능으로 판정되어
**도착 지점 보정과 스폰이 벽 속으로 들어간다.**

히든 방 벽이 있는 **6개 층**에서 확인한다.

```
Goblin1F / Goblin2F / Orc1F / Orc2F / Vampire1F / Vampire2F
 └─ [C] WalkableArea
          Floor     → 1Floor 의 Tilemap        (연결됨)
          Guide     → 1FGuide 의 Tilemap       (연결됨)
          Breakable → 1FHiddenRewards 의 Tilemap   ★ Goblin 둘만 되어 있다
```

> 확인법 — `Pretty Knights > Areas > 0. 포탈 링크 점검` 은 이걸 안 본다.
> 인스펙터로 6곳을 직접 본다.

---

## 2. 벽에 `DestructibleTilemap` 이 붙었는지

**6개 다 붙어 있다** (2026-08-09 확인). 값만 확인한다.

```
1FHiddenRewards  (GameObject)
 ├─ [C] Tilemap · TilemapRenderer
 ├─ [C] TilemapCollider2D        Used By Composite 켬
 ├─ [C] CompositeCollider2D
 ├─ [C] Rigidbody2D              Body Type: Static
 └─ [C] DestructibleTilemap
          Hp Per Cell  → 60      기본 공격 ATK 20 이면 세 대
          Defense      → 0
          Damaged Tint → 기본값
```

> ⚠ **Breakable 을 그린 칸은 `Guide` 에서 비워야 한다.** 겹쳐 있으면 벽을 부숴
> 그림이 사라져도 아래 `Guide` 콜라이더가 남아 지나갈 수 없다.
> **겉보기엔 뚫렸는데 못 가므로** 원인을 찾기 어렵다.

## 3. 방 안쪽을 `NoSpawnZone` 으로 표시한다 — 이번 작업의 본체

### 어떤 모양이든 두 방법 중 하나

| 방 모양 | 방법 | 손이 가는 정도 |
|---|---|---|
| 직사각형 하나 | `Size` 만 맞춘다 | 가장 쉽다 |
| ㄱ자 · ㅗ자 | 사각형 여러 개 + **`Room Id` 를 같게** | 방마다 2~3개 |
| 곡선 · 들쭉날쭉 | **`Mask` 에 타일맵** — 칠한 칸이 곧 구역 | **권장** |

**타일맵 방식을 권한다.** 맵 그리는 것과 같은 손놀림이고, 판정이 칸 조회 한 번이라
사각형 여러 개를 겹치는 것보다 오히려 싸다. 그리고 **방 모양이 바뀌어도 다시 칠하면 끝**이다.

### 타일맵 방식

층마다 타일맵을 하나 더 만든다. 벽 타일맵 옆에 나란히 둔다.

```
Goblin1F
 ├─ 1Floor / 1FGuide / 1FHiddenRewards       (기존)
 │
 ├─ 1FNoSpawn  (GameObject)                  ← 추가
 │    ├─ [C] Tilemap
 │    └─ [C] TilemapRenderer   ★ 컴포넌트는 두되 **끈다** (판정에만 쓴다)
 │
 └─ HiddenRooms  (GameObject)                ← 추가. 묶음용
      └─ Room_1F  (GameObject)
           └─ [C] NoSpawnZone
                    Mask                   → 1FNoSpawn 의 Tilemap   ★
                    Size                   → 무시된다
                    Blocks Monsters        → 켬
                    Blocks Props           → 켬
                    Reveal On Player Enter → 켬
                    Room Id                → 비움 (타일맵 하나가 층의 모든 방을 담으므로)
```

**칠할 것은 방 안쪽 바닥 전부**다. 벽칸은 안 칠해도 되고 칠해도 무해하다.
층에 히든 방이 여럿이면 **한 타일맵에 다 칠한다** — 벽 타일맵을 층당 하나로 둔 것과 같은 이유다.

> 타일은 아무거나 쓴다. 렌더러를 끄므로 보이지 않는다.
> 에디터에서는 타일맵을 선택하면 칠한 칸이 보인다.

### 사각형 방식

`Mask` 를 비우고 `Size` 를 쓴다. 방 하나를 여러 사각형으로 덮을 때는
**`Room Id` 를 반드시 같게 준다.**

```
Room_1F_A   Size (8, 6)   Room Id → 1f_north
Room_1F_B   Size (6, 4)   Room Id → 1f_north     ← 같은 이름
```

안 주면 플레이어가 들어간 사각형만 봉인이 풀리고 **나머지 절반에는 계속 몬스터가 안 나온다.**
겉으로는 "가끔 안 나온다" 로 보여 원인을 찾기 어렵다.

---

## 4. 들키면 어떻게 되나

플레이어가 방 안에 들어오면 **몬스터 차단만** 풀린다.

| | 들키기 전 | 들킨 뒤 |
|---|---|---|
| 몬스터 스폰 | 막힌다 | **열린다** |
| 오브젝트 배치 | 막힌다 | **계속 막힌다** |

오브젝트가 계속 막히는 이유는 **배치가 그 층의 지형이기 때문**이다.
탈출했다 돌아왔을 때 없던 바위가 생기면 길을 처음부터 다시 찾아야 한다
([`../design/map-objects.md`](../design/map-objects.md) §4).

- 해제는 **세이브에 남는다.** 층을 껐다 켜도 다시 봉인되지 않는다
- **테마를 완전 클리어하면 다시 봉인된다.** 벽도 함께 되살아나므로 짝이 맞는다
- 히든 상자를 열었을 때처럼 밖에서 열려면 `NoSpawnZone.Reveal()` 을 부른다
- **콜라이더를 쓰지 않는다.** 같은 도형 판정을 0.25초마다 물어본다

## 5. 확인

1. 재생 → 히든 방이 있는 층으로
2. **벽을 때린다** → 데미지 숫자가 없으므로 **색이 어두워지는 것**으로 확인한다
   (일반 벽은 아무 반응이 없다)
3. 세 대쯤 때리면 칸이 사라지고 지나갈 수 있다
4. 방 안에 **몬스터도 오브젝트도 없어야 한다**
5. 방 안으로 들어간다 → 잠시 뒤부터 **몬스터가 방 안에도 뿌려진다**
6. 층을 나갔다 온다 → 벽은 부서진 채, 방은 **계속 열린 채**

### 안 되면

| 증상 | 원인 |
|---|---|
| 벽을 때려도 아무 반응이 없다 | 그 타일맵에 `DestructibleTilemap` 이 없다 |
| 색이 안 변한다 | 알려진 함정 — `SetTileFlags(TileFlags.None)` 누락. 코드는 이미 처리함 |
| 부쉈는데 못 지나간다 | 같은 칸에 `Guide` 타일이 남아 있다 (2절 ⚠) |
| 부수기 전인데 방 안에 몬스터가 있다 | `NoSpawnZone` 이 없거나 `Mask`/`Size` 가 방을 안 덮는다 |
| 도착 지점이 벽 속에 잡힌다 | `WalkableArea.Breakable` 이 비었다 (1절) |
| 방 절반에만 몬스터가 나온다 | 사각형 여러 개인데 `Room Id` 를 안 줬다 |
| 들어갔는데도 몬스터가 안 나온다 | `Reveal On Player Enter` 가 꺼졌거나, 층에 스폰 자체가 없다 |

## 6. 이 문서 범위 밖

- **히든 방에 무엇을 둘지** — 상자·아이템. 아이템 시스템이 아직 없다
- **입구 규격** — 몇 칸을 부숴야 뚫리는지. 지금은 칸당 HP 60 뿐이다
  ([`../design/map-objects.md`](../design/map-objects.md) §6 미결)
- **벽 강도를 방마다 다르게** — 타일 종류로 가를 수 있다 (`../TODO.md` 3-2)
- **발견성** — 데미지 숫자가 붙으면 "때렸더니 숫자가 뜬다" 가 유일한 단서가 된다
